# 🏸 Smash Fit — ฟิตเนสสำหรับนักแบดมินตันวัยทำงาน

เว็บแอปส่วนตัว ใช้บน iPhone เหมือนแอปจริง (เปิดได้แม้ไม่มีเน็ต) ไม่ต้องขึ้น App Store

## ขึ้นเว็บครั้งแรก (ให้ Claude Code ทำ)
เปิดโฟลเดอร์นี้ใน Claude Code แล้ววางข้อความจากไฟล์ `CLAUDE_CODE_PROMPT.md`

ถ้าทำเอง:
1. สร้าง repository ใหม่บน GitHub ชื่อ `smashfit` (Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น branch `main`
3. ไปที่ Settings → Pages → Source: “Deploy from a branch” → Branch `main` โฟลเดอร์ `/docs` → Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้ GitHub>.github.io/smashfit/`

## ติดตั้งบน iPhone
1. เปิดลิงก์ด้านบนใน **Safari**
2. กดปุ่มแชร์ ⬆︎ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าจอโฮมทุกครั้ง (ข้อมูลจะอยู่ในแอปนั้น)

## ย้ายข้อมูลจากเวอร์ชันเดิม
ในแอปเดิม: ตั้งค่า → สำรองข้อมูล → ดาวน์โหลดไฟล์สำรอง (หรือคัดลอกข้อความ)
ในแอปใหม่: ตั้งค่า → กู้คืนจากไฟล์ (หรือวางข้อความ)

## ดึงข้อมูลจากแอป Health อัตโนมัติ (ไม่บังคับ)
สร้างคำสั่งลัดในแอป “คำสั่งลัด” ให้เปิด URL:
`https://<ชื่อผู้ใช้>.github.io/smashfit/?sleep=<ชั่วโมงนอน>&rhr=<ชีพจรขณะพัก>`
รายละเอียดทีละขั้นอยู่ในแอป: ตั้งค่า → ดึงข้อมูลจากแอป Health

## ความเป็นส่วนตัว
โค้ดของแอปอยู่บน GitHub แบบสาธารณะ แต่ **ข้อมูลการฝึกของคุณไม่ได้อยู่บน GitHub** เก็บอยู่ในเครื่อง iPhone เท่านั้น — สำรองข้อมูลทุก 1–2 สัปดาห์

## แก้ไข/เพิ่มฟีเจอร์
บอก Claude Code ได้เลย เช่น “เพิ่มท่า … ”, “เปลี่ยนสี …” — รายละเอียดโครงสร้างอยู่ใน `CLAUDE.md`
หลังแก้ทุกครั้ง: `python3 build.py` → commit → push แล้วเปิดแอปใหม่ 1–2 ครั้งเพื่อรับเวอร์ชันล่าสุด
